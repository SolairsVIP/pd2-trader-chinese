这是 PD2 Trader 的中文本地化分支。本仓库当前版本为 **0.11.0 中文版**，保留中文版 0.10.6 中恢复出的中文界面和词缀翻译，整合技能查价修复、物品名称汉化与中文市场搜索。

## 历次修复记录

下面的检查数量对应各自当时的修复记录，不代表本次聚气修复重新运行了全部测试。

2026-10-24 查价修正：修复稀有／手工物品的自动估价返回普通说明时，汉化函数处理缺失的可选标题而导致整个查价窗口崩溃的问题。自动估价暂不可用时，词缀筛选与市场搜索仍可使用。针对可选文本、即时返回、延迟返回和再次查价的 12 项回归检查已通过；截图中原物品仍需在游戏内复测。

2026-10-24 技能筛选修正：根据用户提供的 Katar 原始复制数据，兼容缺失 `stat_id` 的普通 `+N to <skill>` 加成；将 `Claw and Dagger Mastery` 与旧名称 `Claw Mastery` 对应到同一个技能编号 252，并补充中文显示。复选框可用状态、外部市场链接及内置市场查询共用技能映射。带技能等级或触发几率的属性不会按这一兼容规则当成普通技能加成处理。本项仍需在游戏内复测。

2026-10-24 技能全面补齐：统一单项技能、非本职业技能、7 个职业、21 个技能树、10 类触发条件、光环、装备时技能、聚气与元素技能加成的查询规则。修正同名技能的勾选冲突、职业限定名称缩短后身份丢失、聚气剩余次数及元素技能数值字段错误。核心回归检查 1124 项通过，查价界面专项集成检查 9 项通过，完整前端类型检查通过。本次没有修改 Rust 后端、覆盖层或登录代码。详见 [技能查价修复与验证记录](docs/技能查价修复与验证-20261024.md)。

覆盖层默认以普通窗口启动，仅在游戏上下文激活时置于游戏上方；从托盘在桌面打开设置等界面时不会置顶。浏览器或其他程序成为前景时，覆盖层会在不激活自己的情况下退出置顶。

## Windows 构建

需要 Node.js、Rust 工具链和 Windows C++ 构建工具。在仓库根目录安装 npm 依赖后运行：

```powershell
npm ci
npm run tauri -- build --bundles nsis
```

NSIS 安装包生成于 `src-tauri/target/release/bundle/nsis/`。
