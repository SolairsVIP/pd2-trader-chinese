# 0.11.11 更新内容

- 管理挂单新增刷新按钮，重新打开时更新列表，并改进搜索与加载提示。
- 聊天会话支持右键菜单；市场中已打开过聊天的卖家卡片变暗，悬停可查看密语记录。
- 优化游戏密语账号识别和复制命令，改进切换窗口后的消息模板操作。
- 修正部分刺客技能树名称的识别与查价筛选。

英文和汉化游戏客户端继续使用同一安装包。繁体中文客户端的市场装备查找与查价将在未来版本更新；繁体词缀搜索暂未支持。

开启自动检查的用户会收到新版提示，由用户点击安装；也可在“设置 → 更新”中手动检查。
