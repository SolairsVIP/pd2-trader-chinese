# 0.11.9 更新内容

- 腐化区提示新增独立背景透明度滑块：在“设置 → 腐化区提示 → 显示与位置”调整，独立于插件整体透明度，文字和倒计时保持清晰。
- 右下角红石图标新增“腐化前试试手气”入口：七档诙谐提示与专属音效，重复点击不叠音，关闭或切走页面时停止播放。仅供娱乐，不影响游戏内腐化结果。

一份安装包兼容英文和汉化游戏客户端。0.11.2 及以上版本可通过“设置 → 更新”检查并安装；开启自动检查的用户会收到新版提示，由用户点击“下载并安装”升级。
