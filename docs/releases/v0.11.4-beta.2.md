# 0.11.4-beta.2 浮窗市场入口测试版

特别感谢原作者 **[errolgr](https://github.com/errolgr)** 及 [errolgr/pd2-trade](https://github.com/errolgr/pd2-trade) 的所有贡献者。汉化维护：Solaris；保留 MIT 许可证。

## 更新内容

- 游戏右下角浮窗的聊天图标上方新增商店图标，悬停显示“交易大厅”，点击直接打开市场，无需先展开菜单或按快捷键。
- 复用已有市场打开入口与面板状态；原来的“更多 → 交易大厅”和市场快捷键继续可用。
- 浮窗向上增加一行，保留聊天和报价按钮的点击空间，支持原有拖动、位置保存及靠近顶部时菜单向下展开。
- 拖动后释放不会误触市场按钮；点击市场时收起已展开的“更多”菜单。
- 包含 beta.1 的全部 33 种中文符文及同类宝石识别修复。

入口随原有聊天浮窗设置显示或隐藏，仍仅在游戏处于前台时显示。此次没有更改原生覆盖层、焦点、官网登录或自动更新逻辑。

## 安装与测试

先退出旧程序及托盘进程，安装后确认版本为 **0.11.4-beta.2**。

1. 在游戏右下角找到聊天图标上方的商店图标，悬停确认“交易大厅”，点击打开市场。
2. 核对原有聊天、报价、更多菜单及市场快捷键仍可使用。
3. 拖动浮窗到不同高度，确认拖动不会误开市场、图标保持可见，靠近顶部时更多菜单向下展开。
4. 切换到其他应用，确认浮窗隐藏；关闭聊天浮窗设置时，市场图标随之隐藏。
5. 复测古尔符文及其他符文的查价和上架。

浮窗组件与打开行为的 18 项检查通过；符文、仓库匹配和查询的 187 项针对性检查已在 beta.1 通过。完整构建再次执行 TypeScript 检查。真实游戏仍需用户实测。

本版仅供本地测试，正式发布与自动更新仍保持 0.11.3。
