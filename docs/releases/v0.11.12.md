# 0.11.12 更新内容

- 腐化区提示新增迷你模式，显示区域名称和倒计时；默认位于左上角，可拖动或切换回完整模式。
- 缩小右下角功能栏，并调整其在全屏窗口中的位置，减少按钮被遮挡。

繁体中文客户端的市场装备查找与查价将在未来版本更新；繁体词缀搜索暂未支持。

开启自动检查的用户会收到新版提示，由用户点击安装；也可在“设置 → 更新”中手动检查。
