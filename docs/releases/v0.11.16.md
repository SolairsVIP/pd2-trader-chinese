# 0.11.16 更新内容

- PS4 / PS5 手柄及兼容的 PS 模拟手柄：短按并松开 L2 + R2 查价，长按打开手柄功能菜单，可进入交易大厅、聊天、上架管理、仓库、腐化区和设置等窗口。
- 手柄功能窗口支持左摇杆移动光标、右摇杆滚动，✕ 确认、○ 返回，L1 / R1 切换选项卡；输入文字时可使用实体键盘。光标速度可在“设置 → 手柄”调整。
- Xbox / XInput 手柄仅支持查价：按 LT + RT 查价，左摇杆移动光标、右摇杆滚动，A 确认、B 返回；不提供其他窗口的手柄控制。
- 市场“提醒记录”新增“实时弹出全部市场提醒”开关，可选择每条匹配分别弹窗，或按 30 秒间隔汇总；匹配较多时会依次显示，提醒记录保留 30 分钟。
- 实时提醒依赖网络连接；断线重连时客户端每次最多补取最近 100 条，超过此数量的较早记录可能不会弹窗。
- 调整手柄窗口切换及返回行为，从腐化区提示返回游戏时保留提示条并移除手柄光标。
- 修正市场中部分中文属性名称显示异常，以及稀有物品底材名称重复显示的问题。
- 修复上架管理中重复加载、模板编辑位置错乱、排队数量判断及下架失败提示等问题。

**Xbox 手柄已知问题：**查价窗口获得焦点后，游戏仍可能同时响应手柄操作，导致人物或游戏内光标移动、按键冲突。此前的测试表明仅切换窗口焦点不能可靠解决该问题；B 键对游戏的影响也尚待实机验证。建议遇到冲突时使用鼠标操作查价窗口。

开启自动检查的用户会收到新版提示，也可在“设置 → 更新”中手动检查。
