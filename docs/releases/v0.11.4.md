# PD2 Trader 中文版 0.11.4

特别感谢原作者 **[errolgr](https://github.com/errolgr)** 及 **[errolgr/pd2-trade](https://github.com/errolgr/pd2-trade)** 的所有贡献者！本项目基于原作者的开源成果进行汉化与兼容修复。汉化维护：**Solaris**；保留 **MIT** 开源许可。

## 更新内容

- **浮窗新增市场入口**：游戏右下角聊天图标上方新增商店图标，悬停显示“交易大厅”，点击直接打开市场。原快捷键和“更多”菜单入口继续可用。
- **保留按钮空间和拖动操作**：浮窗向上增加一行，聊天、报价按钮仍便于点击；拖动结束不会误开市场，原有位置保存与菜单展开方向继续生效。
- **修复中文符文识别**：补齐现有简体客户端中全部 33 种符文名称，古尔符文可正确转换为 `Gul Rune`，用于查价及官网仓库匹配。
- **补齐同类漏项**：修复普通／堆叠物品代码合并条目的名称导入，同步补齐 13 种宝石与大长刀，新增 93 条输入别名，保留原有映射。

本版整合 0.11.4-beta.1 与 beta.2，并包含 0.11.3 的上架、中文属性搜索和提示汉化修复。一份安装包继续兼容英文与已适配的汉化游戏客户端；此次不代表完成繁体客户端全面适配。

预设交易消息继续发送英文；上架提交官网返回的原始物品及 hash。浮窗入口随原有浮窗设置显示或隐藏，没有修改原生覆盖层、窗口焦点或官网 OAuth 登录逻辑。

## 安装与更新

0.11.2 及以上版本可在“设置 → 更新”检查并安装，测试版用户也可升级至正式版 0.11.4。自动检查默认开启，发现新版会显示中文提示，由用户点击下载安装并重启查价器。

更早版本请先退出旧程序和托盘进程，再安装本版 Windows x64 安装包。

## 开源与验证

完整源码、MIT 许可证及图文功能介绍见 [项目 README](https://github.com/SolairsVIP/pd2-trader-chinese#readme)，PDF 原指南随发布附上；旧截图可能与新版按钮略有差异。

符文、匹配与查询的 187 项检查、浮窗操作的 18 项检查及更新系统的 29 项检查均纳入正式发布验证。检查使用本地模拟数据，不会代替用户执行真实交易。
