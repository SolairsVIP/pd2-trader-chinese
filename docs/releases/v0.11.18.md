# 0.11.18 更新内容

- 在“设置 → 聊天”分别设置聊天消息和市场新挂单提醒音效，内置 5 种音效，也可上传自己的 MP3、WAV 或 OGG 文件（不超过 2 MB）。
- 调整聊天和市场提醒音量时可直接试听，也可手动试听或停止；所选音效与音量会分别保存。
- 默认使用音效 3。原先使用默认提示音的设置会自动切换到音效 3，已选择的其他音效和上传文件会保留。

开启自动检查的用户会收到新版提示，也可在“设置 → 更新”中手动检查。
