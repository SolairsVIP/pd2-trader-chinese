# PD2 Trader 中文版 0.11.5

特别感谢原作者 **[errolgr](https://github.com/errolgr)** 及 **[PD2 Trader](https://github.com/errolgr/pd2-trade)** 的所有贡献者！汉化维护：**Solaris**，保留 **MIT** 开源许可。

## 更新内容

- **优化小窗覆盖层**：修复后方网页、视频黑屏及其他窗口操作受影响的问题。
- **修复窗口激活**：处理切回游戏后浮窗和快捷键失效，以及托盘设置打不开或闪现后消失的问题。
- **完善右下角小窗二级菜单**：点击底部“更多”箭头展开或收起，可进入**聊天、交易大厅、仓库估值、仓库价值、报价、管理上架物品、设置**，也可选择**关闭悬浮按钮**。
- **优化菜单操作**：改善展开、收起、拖动及点击范围，继续兼容英文和已适配的汉化游戏客户端，保留查价、上架及英文交易消息模板。

## 安装与更新

在“**设置 → 更新**”中检查更新，或等待自动检查后的中文提示，点击“**下载并安装**”完成升级。手动安装前请先退出旧程序及托盘进程。

完整源码、MIT 许可证与图文指南见 [项目 README](https://github.com/SolairsVIP/pd2-trader-chinese#readme)，PDF 指南随本次发布附上。
