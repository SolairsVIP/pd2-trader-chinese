# 0.11.3-beta.2 合并测试版

基于 0.11.2，合并 beta.1 的全部上架兼容修复，并补齐提示汉化与中文属性搜索。

特别感谢原作者 **[errolgr](https://github.com/errolgr)** 及 **[errolgr/pd2-trade](https://github.com/errolgr/pd2-trade)** 的所有贡献者。汉化维护：Solaris；保留 MIT 开源许可。

## 本次更新

- **中文客户端上架兼容**：恢复可逆的复制乱码，转换为英文装备身份后匹配仓库，最终提交官网原始物品和 hash。用户已反馈 beta.1 在中文客户端环境能成功上架底材和物品，无报错；本版保留这些修复。
- **属性搜索支持中文**：输入“召唤”可找到死灵法师与德鲁伊的召唤技能树及相关单项技能；支持中文片段、空格分词、中英混合、原有英文缩写与常见中文简称。搜索返回的官网属性键和技能编号不变。
- **输入法兼容**：中文输入法按 Enter 确认候选文字时，不提前选择属性。
- **提示补译**：上架成功标题、说明、“查看挂单”按钮，以及排队、登录、报价接受／拒绝／撤回、聊天通知、撤销、表单校验、重复宏名称和辅助提示。
- **错误显示**：仓库匹配、价格查询、挂单加载和仓库估值等异常统一显示中文说明，保留 HTTP 状态码；已有详细中文错误继续显示。

这是一份兼容英文和汉化游戏客户端的中文版安装包。玩家发送或收到的消息、英文消息模板、账号名称、价格备注、API 参数均保留原数据。没有更改 Rust 窗口覆盖层、焦点算法或官网授权协议。

## 测试步骤

1. 完全退出旧版，安装后在设置中确认版本 **0.11.3-beta.2**。
2. 中文客户端中上架一件底材和一件装备，确认能找到官网仓库物品，并核对上架成功提示为中文。
3. 市场左侧属性栏输入 **召唤**，分别选择死灵法师和德鲁伊的召唤技能树，设定最小值后搜索。也可输入 **力量、施法速度、Necromancer 召唤、fcr** 复测。
4. 验证中文输入法 Enter 选字不会意外添加筛选条件；鼠标点击及普通 Enter 可正常选择。
5. 检查登录、报价操作和聊天通知的提示；确认快捷消息发给对方的仍是英文。

旧队列按原来的上架意图继续检查。若已排除目标候选，取消旧队列后重新选择目标。

本版仅本地分发测试，未推送到正式自动更新通道。新版本的游戏内完整回归仍需实测。详细本地验证见 [提示汉化与属性搜索验证](../提示汉化与属性搜索验证-20261025.md)。
