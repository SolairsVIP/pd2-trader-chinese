# 0.11.15 更新内容

- 新增手柄快捷查价：PS4 / PS5 手柄使用 L2 + R2，Xbox / XInput 手柄使用 LT + RT。
- 查价窗口支持左摇杆移动插件光标、右摇杆滚动，✕ / A 点击，○ / B 关闭；可在设置中的“手柄”栏调整光标速度或关闭快捷查价。
- 聊天窗口新增清除全部聊天记录功能，操作前会提示确认。
- 改善部分技能属性的识别与筛选，包括 Enchant Fire。

**Xbox 手柄已知问题：**操作查价窗口时，游戏仍可能响应同一手柄，导致插件光标和游戏内光标同时移动，其他按键也可能与游戏操作冲突。此问题尚未修复；建议暂时使用鼠标操作查价窗口。

开启自动检查的用户会收到新版提示，也可在“设置 → 更新”中手动检查。
