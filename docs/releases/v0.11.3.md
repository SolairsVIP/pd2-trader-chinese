# PD2 Trader 中文版 0.11.3

特别感谢原作者 **[errolgr](https://github.com/errolgr)** 及 **[errolgr/pd2-trade](https://github.com/errolgr/pd2-trade)** 的所有贡献者！本项目基于原作者的开源成果进行汉化与兼容修复。汉化维护：**Solaris**；保留 **MIT** 开源许可。

本次正式版整合已通过用户实测的 0.11.3-beta.2，同时兼容英文和汉化游戏客户端。

## 更新内容

- **中文客户端上架修复**：恢复可逆复制乱码，转换为标准英文装备身份后匹配官网仓库，使用官网原始物品及 hash 提交上架。
- **排队与匹配优化**：排队时刷新仓库，显示具体失败原因；有多个候选时手动选择，取消排队后不会继续自动上架，并保留初始排除规则。
- **中文属性搜索**：支持“召唤”等中文、中英混合及常用简称，保留原有英文缩写和官网查询编号；修复中文输入法回车确认时误选属性。
- **补全提示汉化**：补齐上架、排队、登录、报价、消息通知、表单和常见错误说明；上架成功按钮显示“查看挂单”。
- **保留交易与更新行为**：预设消息模板继续发送英文；自动检查更新，发现新版后提示，由用户点击下载安装。

本版没有更改覆盖层与窗口焦点逻辑、官网 OAuth 授权协议。玩家原始消息、账号、价格备注及接口标识保持原数据。

## 安装与更新

0.11.2 及以上版本可在“设置 → 更新”检查并安装；自动检查默认开启。更早版本请先退出旧程序及托盘进程，再安装本版 Windows x64 安装包。测试版用户同样可以升级至正式版 0.11.3。

完整源码及 MIT 许可证随仓库公开；图文功能说明见 [项目 README](https://github.com/SolairsVIP/pd2-trader-chinese#readme)，原 PDF 同时附于发布附件。

beta.2 已通过用户实测；相关代码通过 1,001 项针对性测试与 TypeScript 检查。正式构建另外核对版本一致性、更新行为、安装包签名及发布附件。未将这些针对性测试描述为全仓库测试通过。
