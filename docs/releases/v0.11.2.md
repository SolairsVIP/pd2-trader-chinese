# PD2 Trader 中文版 0.11.2

**感谢原作者 [errolgr](https://github.com/errolgr/pd2-trade) 开源 PD2 Trader。汉化及中文客户端兼容维护：Solaris。**

- 新增默认开启的自动更新检查：启动后及每隔 30 分钟检查中文版新版，弹出中文提示。用户点击“下载并安装”后才下载安装并重启查价器。
- 设置新增“更新”页，可关闭自动检查、手动检查新版、阅读更新说明和打开 GitHub 发布页。
- 更新仅来自本汉化仓库，安装前验证独立更新签名；检查、下载或验证失败时保留当前版本。更新使用现有通知区域，不新增模态覆盖层。
- 包含 0.11.1 的技能全面复查修复：标枪技能拼写、无编号技能、职业错名、18 个技能树编号及诅咒触发版本修正。
- 同一份中文版继续兼容英文游戏客户端与汉化游戏客户端；预设交易消息继续发送英文。

**旧用户请先手动安装一次 0.11.2。** 此前中文版关闭了更新组件，无法依靠本次更新远程激活。首次升级默认启用“检查并提示”；此后用户关闭的偏好会保留。未来发布更高正式版本后，已启用自动检查的用户会在启动后或下一次定期检查时收到提示，需要能够连接 GitHub。

本版已完成更新专项逻辑检查、源码类型检查和安装包签名验证；游戏内双客户端实测及一次真实的跨版本安装仍需用户验证。
