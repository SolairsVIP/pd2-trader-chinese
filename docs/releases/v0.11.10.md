# 0.11.10 更新内容

- 优化覆盖层拖动刷新及闲置登录提示的关闭逻辑，减少拖动闪烁及窗口遮挡；实际效果可能因游戏和系统环境而异。
- 收藏优先使用官网，接口不可用时按账号保存本机收藏；重新打开市场时检查官网，本机收藏不会自动同步。
- 常规设置新增简繁显示切换，腐化区提示及部分插件界面支持繁体显示。地区译名优先采用提供的“原版繁”和“修正简”对照。

英文和汉化游戏客户端继续使用同一安装包。繁体中文客户端的市场装备查找与查价将在未来版本更新；繁体词缀搜索暂未支持。

0.11.2 及以上版本可通过“设置 → 更新”检查并安装；开启自动检查的用户会收到新版提示，由用户点击安装。
