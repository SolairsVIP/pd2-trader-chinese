# 0.11.17 更新内容

- 优化手柄功能菜单关闭后的焦点交接，在市场固定时也会尝试将控制权交还游戏；从菜单进入其他插件窗口时继续保留插件操作。
- 取消已关闭菜单尚未完成的窗口激活请求，避免关闭后重新抢占焦点。
- 调整 Windows 窗口激活方式，降低关闭手柄菜单时界面线程卡死的风险；增加无敏感信息的焦点诊断日志。

本次修正在自动化测试中通过；关闭菜单后的卡死现象尚未使用本正式版在游戏中复测。如仍遇到卡死，请反馈使用的手柄及操作步骤。

**Xbox 手柄已知问题：**查价窗口打开时，游戏仍可能同时响应手柄操作，导致人物或游戏内光标移动、按键冲突；B 键对游戏的影响也尚待实机验证。遇到冲突时可使用鼠标操作查价窗口。

开启自动检查的用户会收到新版提示，也可在“设置 → 更新”中手动检查。
