# PD2 Trader 中文版 0.11.6

特别感谢原作者 **[errolgr](https://github.com/errolgr)** 及 **[PD2 Trader](https://github.com/errolgr/pd2-trade)** 的所有贡献者！汉化维护：**Solaris**，保留 **MIT** 开源许可。

## 更新内容

- **修复中文客户端装备识别**：支持墓歌等装备的中英混合底材、物品名和技能；完整英文名称仍在时，兼容乱码中文前缀。
- **修正非本职业技能筛选**：补齐固定装备缺失的技能类型，保证界面选中、官网链接及查价请求一致。
- **完善简繁中文兼容**：增补客户端名称别名，支持繁体聚气次数格式，并兼容旧式颜色标记。
- **增加批量回归检查**：核对查价、上架与技能筛选，保留英文客户端兼容。

## 安装与更新

在“**设置 → 更新**”检查更新，或等待自动检查后的中文提示，点击“**下载并安装**”完成升级。手动安装前请先退出旧程序及托盘进程。

完整源码、MIT 许可证与图文指南见 [项目 README](https://github.com/SolairsVIP/pd2-trader-chinese#readme)，PDF 指南随本次发布附上。
