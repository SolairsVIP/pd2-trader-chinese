# 正式版更新记录约定

更新记录按用户要求，以正式版本为单位汇总。软件内更新记录、GitHub Release、自动更新提示和 README 保持一致。

- 每个正式版只写一条对应版本的更新记录，将本轮测试版的改动整合为简短的用户可见功能与修复说明。
- 不在面向用户的更新记录中逐项列出 beta 编号、试错过程、诊断细节或测试日志。
- 新增或完善入口、按钮、二级菜单时，写明打开方式及实际菜单名称；名称以源码界面为准。
- 发布说明使用简短中文，保留原版开发者感谢、MIT 许可、中文版开发者 Solaris 和安装更新方式。
- 后续版本统一使用“原版开发者”和“中文版开发者”署名；保留原版开发者身份及上游链接，Solaris 署名为“中文版开发者”。软件关于页、README、发布说明及新制作的指南保持一致；历史发布附件不追溯替换。腐化区单独保留“腐化区提示作者：Blyat”署名。
- 软件“关于”页面上方单独显示“中文版开发者：Solaris”，下方以“致谢：”为标题列出原版开发者和腐化区提示作者 Blyat。
- 验证、构建、签名和诊断记录单独保存，不混入产品更新内容；发布前核对版本、附件与更新签名，发布后核对公开更新源。

例如 0.11.5 将本轮小窗、窗口激活和托盘设置修复合并介绍，并列出右下角“更多”中的聊天、交易大厅、仓库估值、仓库价值、报价、管理上架物品、设置和关闭悬浮按钮。
