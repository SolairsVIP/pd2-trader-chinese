# 全功能手柄操作设计

目标是在 PS4 / PS5 手柄及模拟 PS 手柄的兼容第三方设备上操作插件中的市场、聊天、上架、设置及其他功能窗口。Xbox / XInput 仅开放查价窗口操作。

- 短按并松开 L2 + R2：对当前游戏物品查价。长按同一组合：打开插件功能菜单；一次按键只触发一种操作。
- 菜单提供市场、聊天、上架管理、设置和其他现有功能入口。插件内左摇杆控制光标、右摇杆滚动，✕ / A 确认，○ / B 返回或关闭；沿用现有的光标速度设置。
- 在市场搜索和聊天等文本框用手柄选中输入框后，直接使用实体键盘输入；不接入 Windows 屏幕键盘。
- 光标与操作应跟随当前活动窗口及其弹出层；多个窗口、弹窗、窗口关闭和切换时避免重复触发。需要确认所有可操作控件，包括下拉框、对话框、滚动区域及文本输入。
- 第三方手柄必须模拟受支持的 Sony HID 设备及报告格式；未覆盖的型号或其他模拟模式无法保证兼容。
- Xbox / XInput 使用 LT + RT 打开查价，左摇杆移动插件光标、右摇杆滚动，A 确认，B 返回；不提供手柄功能菜单或其他窗口的手柄操作。
- 所有破坏性操作沿用原有确认流程；游戏输入冲突可能导致误操作，应在设置及测试版说明中明确提示。
- 测试短按、长按、松开、重复触发、断开重连和焦点切换；对市场、聊天、上架和设置进行 PS 手柄及兼容第三方设备实机回归。

## 已放弃的 Xbox 输入隔离实机验证（2026-10-29）

- 在测试电脑安装 HidHide，已安装 ViGEmBus。临时隐藏 Xbox 手柄的 HID 子设备、XInput USB 节点和实体 USB 父设备，授权测试程序访问并重新连接手柄后，测试程序仍能读取摇杆，未授权进程读不到实体手柄；用户确认游戏角色不再移动。
- 隔离期间启动临时虚拟 Xbox 手柄，并把实体手柄输入转发给它，用户确认游戏能够识别手柄并控制角色。两轮测试结束后均关闭隐藏、撤销测试添加的设备和程序条目；驱动保持安装。
- 结果只证明此设备和连接方式下的可行性，还没有验证插件窗口打开时将虚拟手柄置为中立、恢复转发、其他控制器及异常退出等场景。

用户决定保留 Xbox 的单一查价功能，但暂不集成 HidHide 或虚拟手柄转发。让插件窗口获得焦点不能可靠阻止 Xbox 输入传到游戏：此前记事本在前台时游戏仍响应手柄。因此查价期间游戏可能同时响应摇杆或按键，B 键在实机上的影响仍待验证。
