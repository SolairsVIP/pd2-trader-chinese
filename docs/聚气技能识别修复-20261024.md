# 0.11.0 双客户端实验版：聚气技能识别修复

用户复制的鬼火投射者（Wisp Projector）含两条独立的聚气记录。每条记录有 `charges`、`level`、`skill`，但没有 `name` 和 `stat_id`。

上一版在技能解析入口直接执行 `stat.name.replace(...)`，因而显示 `Cannot read properties of undefined (reading 'replace')`。已使用游戏剪贴板的原始 UTF-8 数据，在上一提交 b15d229 中复现同一个错误。

## 修复内容

- 在共享技能解析入口处理独立聚气字段，适用于中文和英文游戏物品。
- 根据明确的聚气结构补充显示名称和属性编号 204，不把它误作普通“+技能”。
- 保留真实技能等级、剩余次数和总次数。零次剩余有效；次数超限、未知技能或缺少等级的属性不生成精确筛选。
- 缺少名称时仍返回安全的属性对象；无法识别的属性不会因名称缺失而中断整个物品的解析。
- 对外网站链接和市场 API 继续使用原有聚气参数顺序：技能等级、技能编号；次数筛选使用第三项。

已核对英文独立聚气字段、原有英文整句聚气标签、零次剩余、次数超限、未知技能、缺少等级及缺少名称的记录，并核对网站链接和 API 的聚气参数。本轮完成应用类型检查及 NSIS 生产构建，未新增或运行测试套件。
