# 0.11.3-beta.2 提示汉化与中文属性搜索验证

日期：2026-10-25。基于 0.11.2 与本地 0.11.3-beta.1，保留已实测的上架兼容修改。

## 问题与处理

用户截图显示上架完成后仍出现 `Item listed!`、`Added to the PD2 marketplace.`，按钮显示英文物品名。本轮改为“物品已上架！”、“已添加到 PD2 交易市场。”及“查看挂单”；队列上架成功使用对应中文说明。

对源码中通知、确认、撤销、错误状态、表单校验、提示属性与可访问名称进行了文本及 TypeScript 语法树搜索，并人工核对用途。补译范围：

| 模块 | 已处理内容 |
| --- | --- |
| 上架与队列 | 成功、失败、数量上限、账号不匹配、入队、选择物品、价格或备注未填、重复宏名称、打开挂单按钮 |
| 登录与账号 | 验证成功、验证失败、超时、浏览器阻止登录窗口、退出成功、授权载入成功 |
| 报价 | 接受、拒绝、撤回、取消接受、隐藏、恢复，以及相应失败提示 |
| 消息通知 | 新报价、查看挂单、交易密语、玩家加入、普通密语标题、新聊天消息、回复按钮 |
| 错误呈现 | 挂单加载、查价、仓库估值、历史与个人资料设置的错误说明；保留 HTTP 状态码 |
| 通用界面 | 撤销、关闭、导航辅助提示、更新记录当前版本与数量、时长单位、组合键和交易者详情提示 |

搜索结果中保留了作为账号、网址、快捷键、API 属性键、程序状态、诊断日志和开发示例使用的英文；没有把这些内部值当作中文标签替换。设置中英文发送模板及其占位示例继续使用英文。玩家消息、官网报价文本、备注与物品数据保留原文，避免更改交易内容。

## “召唤”无法搜索

原因：`searchStats()` 原先只索引英文标签、英文简称及官网属性键，列表显示却调用中文翻译。

修复：把现有中文显示标签加入搜索，支持中文片段、空格分词、中英混合及常见中文简称。对纯英文查询保留原有匹配与排序路径。查询结果仍返回原来的目录对象、属性键和技能编号，不把中文发给官网。中文输入法确认选字时的 Enter 不选择属性。

验证“召唤”可找到 `item_addskill_tab{18}`（死灵法师）和 `item_addskill_tab{40}`（德鲁伊），相关单项技能也可找到。对全部含中文显示标签的属性逐项搜索，确认结果包含原目录对象；鼠标点击和键盘选择均验证提交的属性键不变。

## 人工实测与边界

用户反馈 beta.1 在中文客户端下可正常上架底材和物品且无报错；这是上架兼容的实测反馈，不等于 beta.2 的所有功能已完成游戏内验收。

本轮未改动 Rust 窗口覆盖层、焦点或官网登录授权协议。当前正式更新通道仍保持公开版 0.11.2，beta.2 为本地分发测试包。原始代码与 MIT 许可随源码包提供，README 保留醒目原作者致谢。
