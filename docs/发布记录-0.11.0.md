# 0.11.0 中文版

发布日期：2026-10-24

## 简短更新记录

- 暗金名称补全版：新增 69 个 PD2 暗金中文名、6 个箭矢底材译名，修复市场卡片单手/双手及装备类别漏译。
- 技能显示修正版：采用“修正简”技能译名，补齐职业、技能树、单项技能、触发技能及聚气词缀中文显示，修复部分中英混排。
- 新增暗金、套装、符文之语及底材中文名称，市场支持中文搜索。
- 补齐技能词缀识别，修复部分装备查价异常和筛选参数错误。
- 市场、聊天物品卡片和上架列表同步汉化，对外交易消息继续使用英文。

本版整合上一轮物品名称汉化与技能查价修复，将安装包、程序内版本、npm 与 Cargo 版本统一为 **0.11.0**（0.11 大版本）。上述简短更新记录同时写入程序内“更新内容”。

原有自动更新关闭设置及安装身份继续保留。安装前请完全退出旧版，包括托盘进程。
