# 0.11.0 暗金名称补全版

市场截图中的 `Whispering Mirage`、`Leoric's Mithril Bane`、`Bannerlord's Call` 未收录在此前的原版 D2 译名表中；卡片副标题还直接显示了英文单手/双手和装备类别。本次补充名称显示并统一类别翻译。

## 资料与优先级

采用用户在本次对话中提供的三份附件，以及粘贴的 PD2 物品调整说明中的名称：

1. 原有物品表“英文名＋修正简”保持不变。
2. 新增原版未启用物品表，仍只采用“英文名＋修正简”，并只导入当前 PD2 暗金目录中实际匹配的缺失名称。
3. 用户提供的双语武器、防具清单，只读取完整物品名，不导入章节标题、底材编号或属性。
4. 清单中只有英文的 `Embersworn`、`Ephemeral`、`Skyfall`、`Nethercrux`，使用前面用户粘贴说明中提供的“余烬之誓”“短暂”“天降”“幽冥核心”。

同一名称有多个译法时，保留先匹配的高优先级译名。例如 `Odium` 为“厌恶”、`Giant Maimer` 为“重残”；不使用后续说明的译名覆盖“修正简”。已有原版物品的中文名没有批量替换。

新增数据保存于 `src/lib/pd2-item-supplements.data.json`，与原始导入文件分开。重新导入原版 D2 表不会清除这份 PD2 补充表。

导入命令：

```powershell
node scripts/import-pd2-unique-supplements.mjs <未启用物品表.txt> <双语武器清单.txt> <双语防具清单.txt>
```

## 显示结果

| 英文名 | 中文显示 |
| --- | --- |
| Whispering Mirage | 低语幻象 |
| Leoric's Mithril Bane | 李奥瑞克的秘银祸根 |
| Bannerlord's Call | 领主令箭 |
| War Bolts | 战斗弩矢 |
| Sword | 剑 |
| Crossbow Quiver | 弩箭袋 |
| Hand to Hand | 拳套 |

补充 69 个暗金名称，另将 6 种箭矢底材直接补译为钝头箭、尖头箭、剃刀箭、轻型弩矢、重型弩矢、战斗弩矢。

同一显示词典用于市场、查价、聊天物品卡片及上架列表等已有入口，新增名称也进入中文搜索候选；选择结果仍返回英文原名。英文悬停提示继续保留。

将市场筛选现有的装备类别译名移入共享函数，市场卡片也调用此函数，避免筛选菜单已译而卡片仍显示英文。卡片中的 `One-Hand`、`Two-Hand` 改为“单手”“双手”。

未修改 Rust、覆盖层、窗口管理、登录认证、查价筛选参数、物品编号、对外英文消息或自动更新设置。用户粘贴说明中的平衡数值不写入程序。
