# 0.11.0 技能显示修正版

用户反馈市场物品仍显示 `+2 to Druid Skills`、`+1 to Shape Shifting Skills (Druid Only)` 等英文技能词缀。此前的显示翻译只识别独立技能名及部分完整词缀模板，职业、技能树及数值前缀未统一处理。

## 译名来源

- 采用用户于 2026-10-24 提供的 D2 技能表，只读取“英文名”和“修正简”。技能树额外读取职业列来区分死灵法师和德鲁伊的召唤分页。
- 导入 221 个英文名称，含通用动作、卷轴及一个额外拼写别名；不能将该数字理解为职业技能数量。
- 导入 21 个完整技能树名称，不使用拆分的分页文字片段替换技能名。
- 延续项目内 PD2 新增技能补译，并补齐少量市场内部技能标签。合并后显示词典有 284 个英文键。
- 不采用资料中的技能编号，不根据原版 TBL 行号推算 PD2 技能 ID。

导入命令：`node scripts/import-skill-translations.mjs <技能表.txt>`。

## 修改范围

- 统一职业技能等级、技能树、单项技能、非本职业技能、触发技能、装备光环及聚气显示。
- 保留数值及市场 `{X}` 占位符，让市场筛选、物品卡片、聊天物品提示、查价及上架词缀共用显示翻译。
- 修复 `20% Bonus to Attack Rating` 的中英混排；标题底材类别 `Pelt` 显示为“德鲁伊头饰”。
- 原有中文技能译名继续作为精确识别别名保留；存在同名歧义时沿用拒绝猜测的处理。
- 英文原始数据、市场筛选键和技能编号保持原值，对外交易消息仍使用英文。未修改窗口覆盖层、登录认证或自动更新设置。

显示示例：

| 原文 | 中文显示 |
| --- | --- |
| `+2 to Druid Skills` | `+2 德鲁伊技能等级` |
| `+1 to Shape Shifting Skills (Druid Only)` | `+1 外型变形（德鲁伊专属）` |
| `+3 to Tornado (Druid Only)` | `+3 龙卷风（德鲁伊专属）` |
| `+{X} to Sorceress Fire Skills` | `+{X} 火焰法术（法师）` |
| `+{X} to Fire Skills` | `+{X} 火焰技能等级` |
| `Level 1 Teleport (10/22 Charges)` | `等级 1 传送（聚气：10/22）` |
| `20% Bonus to Attack Rating` | `20% 准确率加成 (AR)` |

## 核对与构建

- `npx tsc -p tsconfig.app.json --noEmit --pretty false`：通过。
- `node scripts/report-skill-translation-coverage.mjs`：市场静态技能标签 543 项，剔除 `{X}` 占位符后未译项 0；逐项结果见 `skill-translation-coverage-20261024.json`。
- `npm run tauri -- build --bundles nsis`：构建 Windows x64 安装包。

以上为代码、静态标签及构建核对，不代表已在游戏内逐技能实测。未来官网新加的未知名称仍保留原文。

版本号仍为 0.11.0，分发文件名追加“技能汉化修正版”以区别上一份安装包。安装前请完全退出旧版及其托盘进程。
