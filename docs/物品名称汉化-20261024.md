# 物品名称汉化：英文名 → 修正简

本轮仅采用用户提供的四份文本表格中的 **英文名** 和 **修正简** 两列。没有使用原版繁、D2R 繁简、菠萝简、底材说明或备注中的译名。

## 导入数据

| 分类 | 分类内英文名称去重后数量 |
| --- | ---: |
| 符文之语 | 171 |
| 底材 | 498 |
| 暗金 | 378 |
| 套装与套装总名 | 187 |
| 合计 | 1234 |

数量包含英文别名、表中未启用条目，以及套装总名；不是游戏当前启用物品数量。不同分类分别保存，不合并同名物品。重复的彩虹刻面行保留一个名称映射。

导入脚本按表头选择两列，处理跨行单元格，并在缺列、同一英文名对应不同修正简或修正简单元格有歧义时停止。仅清除英文单元格中的 `(PD2 wiki)` 标注，保留其中明确给出的英文别名。

翻译数据位于 `src/lib/pd2-item-translations.data.json`。重新导入：

```powershell
node scripts/import-item-translations.mjs <符文之语文本路径> <底材文本路径> <暗金文本路径> <套装文本路径>
```

## 显示与搜索

- 市场卡片、列表、详情、卖家其他挂牌及镶嵌物名称显示译名；英文名保留在悬停提示中。
- 市场搜索候选显示中英文；支持输入中文译名、英文原名和表格中明确列出的英文别名。
- 同一中文名可匹配多个目录结果，由用户选择；不会自动猜测唯一对应物品。
- 底材筛选显示中英文，查询值仍为原来的底材代码。
- 聊天中的物品卡片、关联挂牌选择、上架选择、管理挂单、排队条目、查价标题及仓库估值中的相应名称使用同一显示映射。
- 没有收录的名称保留英文。随机蓝色、黄色装备名称未按前缀后缀拆分翻译。
- 通用词缀和技能翻译保持独立，避免符文之语 `Spirit`、`Fury` 等名称影响技能或说明文字。

## 保持原始数据

翻译函数只返回显示字符串，不修改原始 `item.name`、底材、物品编号、品质、hash 或 modifier。

市场搜索选中候选后，`onChange` 继续返回目录中的英文原名。官网 URL、查价请求、物品图标匹配、仓库匹配、价格代码和上架请求继续使用原数据。发送给卖家的英文模板、密语和物品链接仍使用原英文名称；手动输入的消息内容不会被自动翻译。

本轮没有修改 Rust 后端、覆盖层、窗口管理、登录认证、自动更新及上架队列的同步和超时策略。

## 覆盖边界

提供的表主要是原版 D2 资料，不能覆盖全部 PD2 新装备或后续新增符文之语。运行下列数据对照命令可生成尚无译名的目录名称清单：

```powershell
node scripts/report-item-translation-coverage.mjs
```

输出为 `docs/item-name-translation-coverage-20261024.json`。它比较仓库中的目录名称，不表示所有目录项都在当前赛季启用；上游物品数据中也存在章节占位项。

例如尚缺 `Ferocity`、`Dominion`、`Zenith`、`Zakarum's Salvation` 等名称。没有以其他列的译名或自行推测的译名补上这些名称。

本轮执行了数据提取、目录覆盖对照、应用 TypeScript 类型检查和安装包生产构建；未新增或运行测试套件，未进行真实账号交易或游戏内运行验证。
