# 中文客户端符文兼容排查（2026-10-26）

本次找到并修复两处可复现的问题，已纳入 0.11.8 正式版并完成 Windows 安装包构建和离线验证。发布内容见 [0.11.8 更新说明](./releases/v0.11.8.md)。未在运行中的游戏或线上交易服务中人工验证。

## 原因与修改

1. **带颜色标记的英文符文名被跳过。** 提供的客户端 CHI 文字表包含 `ÿc8Ber Rune` 等名称，以及 `(old)`、`(旧)` 等后缀。原流程按是否含中文决定是否转换，导致部分名称跳过规范化，再被无属性物品的复制校验拒绝。新增精确符文名称转换，在中文判断前处理颜色标记、已知旧版后缀、中英混合名称及有限的繁简异体。
2. **跳转交易大厅时丢失符文筛选。** 符文查询同时包含普通和堆叠代码，例如贝符文为 `r30`、`r30s`。旧转换只读取单个字符串，忽略 `$in` 分组。现保留完整分组并匹配交易大厅的下拉选项。
3. **无名称符文的标题显示。** 未提供 `name` 时使用符文 `type` 显示标题。

转换仅修改已确定的符文类型，不改等级、数量、品质、位置、词缀及插槽顺序。正常英文输入保留原始 JSON；`Rune Bow` 等装备不按符文处理。中英文身份冲突时拒绝猜测，以免查询到另一种符文。

## 验证结果

- 实际读取 `Z:\Diablo II\ProjectD2\data\local\LNG` 下 ENG、CHI 的三份 TBL 文件；仅读取翻译数据，不执行或修改游戏文件。
- 33 种普通符文、33 种旧版／堆叠名称，分别测试正常 UTF-8、UTF-8 被误读为 Latin-1 和 Windows-1252：**396 项通过，0 失败**。源文件 SHA-256 和结果见 [审计报告](./rune-compat-audit-20261026.json)。
- 6 个相关测试文件：**231 项通过**。每种符文均检查复制识别、仓库匹配规范化、查价查询、官网 URL 和交易大厅筛选。
- 查价组件定向集成测试：**4 项通过**，包含无名称、无词缀的带色符文。
- 全客户端兼容回归审计：**30,849 项通过，0 失败**；报告位于工作区 `tmp/game-client-audit-rune-regression.json`。
- `npm run build` 与 Windows NSIS 签名构建通过。排查阶段发现的 9 条既有类型诊断，在发布准备时通过补充技能目录字段检查及修正测试数据类型断言解决；完整应用 TypeScript 检查通过。发布回归共 1,283 项相关测试通过。
