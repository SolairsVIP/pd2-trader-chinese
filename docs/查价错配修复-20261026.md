# Spectral Plate 查价错配修复

日期：2026-10-26。状态：修复已纳入 0.11.8 正式版，Windows 安装包构建完成；发布内容见 [0.11.8 更新说明](./releases/v0.11.8.md)。

用户复制的是暗金胸甲 Spectral Plate，底材 Great Hauberk；交易大厅却搜索妖怪碎片 Spectral Shard，并在查价窗口显示了后者的均价。

## 原因与修复

- 内置 `src/assets/items.ts` 尚未收录 Spectral Plate。原来的 `findOneByName` 在键值查找失败后使用阈值为 0.5 的 Fuse 模糊查找，可稳定复现匹配到 Spectral Shard。该结果同时用于搜索名称、物品图标、均价及腐化均价。
- 查价窗口现使用准确匹配模式，按物品品质核对英文名称或内部键值，兼容大小写、空格和弯引号。无法准确匹配时返回空，查询构造器沿用装备原始名称，不借用相似装备的数据。交互式名称模糊搜索保留。
- 已验证查价窗口搜索、官网搜索链接和“在交易市场中打开”均使用 Spectral Plate；不会向价格接口请求 Spectral Shard 的均价或腐化价格。
- 原始装备技能行只有 `stat_id: 191`、`value: 1` 和未展开的 `Level %d %s When Equipped`，没有技能名称或明确等级。保留该原始属性，显示“装备时赋予技能（名称或等级缺失）”，不能选择该行，其余属性仍能查价；不猜测技能或将数值 1 视为已确认等级。
- 补全截图中 Ethereal 和 Chance of Deadly Strike 的显示翻译，不修改英文物品身份或对外提交数据。

## 验证

- 物品查找、翻译、技能解析、搜索查询构造和市场过滤转换共 1,065 项测试通过。
- 查价窗口技能集成测试 3 项通过，包含本次用户原始胸甲数据的完整回归用例；该组件文件中其余 44 项未在本轮运行。
- `npm run build` 成功。
- 初次排查时额外执行应用 TypeScript 检查，并通过编译器只读覆盖原文件的方式与 HEAD 基线比较：两边均有 9 项既有诊断，本轮无新增诊断。0.11.8 发布准备时补充技能目录字段检查并修正测试数据类型断言，完整应用类型检查已通过。
- 尚未进行新安装包的游戏内人工验证，不承诺已经补全所有新装备目录或缺失技能字段。
