# PD2 Trader 中文版 0.11.0：双客户端兼容实验

本实验版使用同一个安装包读取英文、汉化游戏客户端的装备数据，无需切换语言设置。英文物品文本保持原样；中文物品在游戏复制入口转换为原查询流程需要的字段。插件界面继续使用中文。

后续修复：[鬼火投射者等装备的独立聚气字段与缺失属性名称](./聚气技能识别修复-20261024.md)。两条实际聚气数据已完成本地核对，仍需游戏内验证。

## 本次修改

- 修复汉化游戏把 UTF-8 JSON 放入 Windows CF_TEXT 后，被系统按 ANSI 编码转换而产生乱码的问题。游戏物品读取优先读取原始 UTF-8；原始 Unicode 剪贴板、普通文本和浏览器环境保留原读取方式。
- 仅接受完整合法的物品 JSON，不通过猜引号或替换乱码修复残缺数据。读取长度最多 1 MiB，原生锁在复制字节后立即释放。
- 从用户提供的客户端字符串表，按底材代码、物品键和修正过的技能编号提取别名。数据包括 626 条底材别名、768 条固定物品名、369 条属性标签及 211 条技能名称。条目数量表示映射覆盖，不能视为对应数量的装备已完成游戏实测。
- 查价、快捷上架和下架共用转换入口；保留属性编号、数值、装备等级、孔数、位置及其他原字段。力量缺省的 stat_id 补为 0。随机稀有/魔法名字保留。
- 明确的 `skill` 字段优先于可能出错的中文说明。按客户端中已确认的完整词缀模板识别缺少编号/技能字段的触发技能。
- 未知或同名的中文底材/固定物品名提示无法唯一识别；无法确认的技能保留并沿用不可精确筛选提示，避免选成其他属性。

## 保留与限制

- 本轮没有修改游戏文件、登录/OAuth、聊天发送、窗口覆盖层、托盘或自动更新逻辑。
- 市场浏览、仓库估值等官网返回数据继续走原流程，未对官网数据反向转换。对外消息模板继续使用英文。
- 未识别的嵌入符文/宝石记录保留，不因此阻止主装备查价。
- 尚需实测：汉化客户端上的游戏内查价、共享仓库上架/下架、稀有估值远端服务、聚气/灵气和更多 PD2 专属技能。中文游戏日志的通知格式尚未验证；本版未改日志解析器。
- 别名按当前提供的汉化客户端生成，其他汉化版本可能使用不同译名。无法精确匹配时请提供装备原始复制文本。
- 旧版安装包保留。构建不会改变已安装插件；运行本安装包会更新同一产品身份的中文版，旧版可通过保留的安装包回退。不需要为两种游戏客户端各装一套插件。

## 维护映射

脚本仅读取字符串表，不加载或执行游戏程序/DLL，不读取账号或存档：

```powershell
node scripts/import-game-client-aliases.mjs '<汉化客户端>/ProjectD2/data/local/LNG/ENG' '<用户技能参考表.tsv>'
```

补丁表优先于扩展表，再优先于基础表。输入别名与界面“修正简”展示词典分开维护；客户端中的明确同名冲突不得用展示词典覆盖。
